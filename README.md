# AURENZA-BROKER

A comprehensive trading broker application with wallet management, challenges, and AI assistance.

## Overview

AURENZA-BROKER is a full-stack trading platform offering secure authentication, integrated trading capabilities, an AI-powered assistant, and multi-platform support (Web, Android, iOS).
