A module is complete only when these are satisfied:

- [ ] Screen flow defined
- [ ] Screens implemented
- [ ] Navigation connected
- [ ] Components/states handled
- [ ] Backend contract defined
- [ ] Database/RPC/API connected where required
- [ ] Authorization/permissions enforced
- [ ] Tests added

- [ ] Documentation updated
- [ ] CI passes
